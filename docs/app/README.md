# 몇 번 고치면 되는가 — AI 교정 수렴 도우미

과제 10 논문 **「같은 글을 AI가 반복해서 고칠 때, 고치는 양은 줄어드는가」**(김민기, 2026)의 결과를 실제로 쓰는 앱입니다.

**누구를 어떻게 돕는가**: AI에게 글 교정을 반복해서 시키는 사람이, 고친 글을 붙여넣어 변경률(문자 편집 거리 ÷ 입력 문자 수)을 재면, 논문이 실측한 수렴 데이터로 "언제 멈춰도 되는지"와 "어떤 지시문을 써야 하는지"를 안내해 줍니다.

## 실행 방법

정적 파일이라 서버 없이도 열립니다 — `index.html`을 브라우저에서 그냥 열면 됩니다. Node.js가 있으면 로컬 서버로도 열 수 있습니다:

```
# 이 폴더(app/)에서 아무 정적 서버나
npx serve .
# 또는 파일 탐색기에서 index.html 더블클릭
```

AI 호출·API 키·환경 변수가 필요 없습니다. 모든 계산은 브라우저 안에서 일어나며, 입력한 글은 어디에도 전송되지 않습니다.

## 사용자가 할 수 있는 일 (세 가지)

1. **변경률 측정** — 이전 글/다음 글 두 칸에 붙여넣고 "변경률 재기"를 누르면 논문과 같은 방식으로 재고, 논문 평균과 비교한 판정(수렴·진동·계속)을 보여 줍니다.
2. **회차 추적** — "이 회차를 기록"을 눌러 회차를 쌓으면 내 변경률과 논문 평균(6.91% → 1.49% → 0.62%)이 나란한 막대로 보이고, 수렴 지점 또는 잔존 진동(논문에서 3/10편이 보인 되오름)인지 안내합니다.
3. **지시문 비교** — 조건 A(문체 다듬기 허용)와 조건 B(규범 오류만)의 논문 실측을 비교하고, 실험에 쓴 지시문 원문을 복사해 쓸 수 있습니다.

## 논문의 어느 결과를 쓰는가

- 측정법: 변경률 = Levenshtein 편집 거리 ÷ 입력 문자 수 (논문 §3.1)
- 조건 A 평균 변경률 6.91% → 1.49% → 0.62%, 잔존 진동 3/10편 (§4.1, §4.2)
- 조건 B(규범만 고치라)는 1차 이후 10/10 변경률 0% 완전 수렴 (§4.3)
- 정지 규칙: 변경률이 직전 회차의 10% 미만이거나 0이면 중단 (§5.2 우회 전략 2)

## 데이터

논문의 실제 샘플 문단이 아니라 앱이 새로 만든 예시 문장(오타 섞인 짧은 글 3편)을 씁니다. 개인정보·비밀값 없음.
